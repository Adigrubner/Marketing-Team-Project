# תוכן אורגני - אלעד גרובנר 📱

> כאן יושב כל התוכן האורגני: פוסטים, קרוסלות ורילס לאינסטגרם ולפייסבוק.
> (`campaigns/` שלידה נועדה לפרסום **ממומן** ב-Meta - אלעד לא שם כרגע.)

## מה שונה כאן מלקוח רגיל

אצל רוב העסקים כותבים קודם טקסט, ואז מייצרים תמונה שמתאימה לו.
**אצל אלעד הפוך:** התמונות כבר קיימות - צילומים אמיתיים של פרויקטים - ולכן:

```
בוחרים פרויקט  →  מסתכלים על התמונות  →  בוחרים ומסדרים אותן  →  כותבים קופי שמתאים למה שרואים
```

## הצוות - שלוש סוכנות, כל אחת עושה דבר אחד

```
📅 מתכננת התוכן   →  calendar.md     מה מתפרסם ומתי
        ↓
📸 בוחרת התמונות  →  selection.md    אילו תמונות ובאיזה סדר
        ↓
✍️ כותבת התוכן    →  post.md         הקופי
```

**המסירה ביניהן היא דרך קבצים, לא דרך שיחה.** לכן שום דבר לא הולך לאיבוד, ואת יכולה להיכנס באמצע ולהגיד "התמונה השלישית לא מתאימה" - בלי להתחיל מהתחלה.

## המבנה

```
content/
  README.md      ← הקובץ הזה
  playbook.md    ← סוגי הפוסטים והנושאים (מה מייצרים ולמה)
  calendar.md    ← מה יהיה
  history.md     ← מה כבר היה - הזיכרון שמונע חזרתיות
  posts/
    2026-09-30-penthouse-herzliya/
      selection.md   ← אילו תמונות נבחרו, באיזה סדר, ולמה
      post.md        ← הקופי הסופי + הנחיות פרסום
```

## איך מייצרים פוסט

פשוט לבקש מקלוד בשפה חופשית, והוא יקרא לסוכנת הנכונה:

| מה שתגידי | מי תיקרא |
|------------|-----------|
| "בואי נתכנן את השבועיים הקרובים" | מתכננת התוכן |
| "תכיני קרוסלה מהפרויקט של הרצליה" | כל השלוש, לפי הסדר |
| "תחליפי את התמונה הראשונה" | בוחרת התמונות |
| "הפתיחה חלשה, תכתבי מחדש" | כותבת התוכן |

**מה שצריך להיות מוכן:** `playbook.md` ו-`style.md` מלאים, והפרויקט במאגר עם כרטיס ועם אישור פרסום.

## הפרסום עצמו

אלעד או את מפרסמים **ידנית** באינסטגרם ובפייסבוק. אין כאן העלאה אוטומטית - `post.md` מכיל את הטקסט המוכן להעתקה, את רשימת התמונות לפי הסדר, ואת הקרדיטים והתיוגים.

אחרי הפרסום: מסמנים ב-`calendar.md` שעלה, ומוסיפים שורה להיסטוריית הפרסום בכרטיס הפרויקט.
