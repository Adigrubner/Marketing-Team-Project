# 🎯 מכונת הקמפיינים - פרויקט ה-Starter

ברוכים הבאים! זה הבסיס הרשמי של הקורס "מכונת הקמפיינים" של מועדון 2030.
מכאן מגייסים, שיעור אחרי שיעור, מחלקת שיווק שלמה של סוכני AI.

## מה יש כאן כבר עכשיו
- **CLAUDE.md** - המוח הקבוע: החוקים שקלוד תמיד זוכר (כולל בלם החירום).
- **clients/_template/** - תבנית תיקיית לקוח (בשיעור נעתיק אותה לעסק שלכם).
- **tools/** - הכלים הנעולים לבטיחות: העלאה בטוחה ל-Meta, דוחות, ו-doctor.
- **config/safety.json** - בלם החירום: תקרת התקציב שאף אחד לא עובר.

## מה עוד לא כאן (ובכוונה)
את הסוכנים - הקופירייטרית, הקריאייטיבית, הקמפיינר, האנליסט - ואת הסקילים שהם משתמשים בהם, נבנה **ביחד** בשיעורים. זה הלב של הקורס.

## איך מתחילים (שיעור 2.2)
1. פתחו את התיקייה הזו בקלוד קוד.
2. כתבו לו: "עשה לי סיור בפרויקט".
3. זהו. מכאן ממשיכים בשיעורים.

## פקודות שימושיות
- `npm run doctor` - בודק שהכל מחובר ותקין (עברית, עם הסבר מה לתקן).

## חשוב לדעת
- אין פה שום התקנות - צריך רק Node 20 ומעלה (מותקן בשיעור 1.2).
- הקובץ `.env` הוא הכספת שלכם - לעולם לא משתפים אותו ולא מעלים אותו לשום מקום.
- כל מודעה שנוצרת דרך הפרויקט נוצרת **מושהית (PAUSED)** - שום דבר לא רץ ולא מבזבז שקל בלי אישור ידני שלכם ב-Ads Manager.
