# הסקילים 🛠️

**סוכן = מי · סקיל = איך.**

סוכן הוא העובד (הקופירייטרית, הקריאייטיבית). סקיל הוא **יכולת** שמלמדים את קלוד: תיקייה עם `SKILL.md` (ההוראות - מתי ואיך משתמשים) ולידו, אם צריך, גם המכונה שמבצעת בפועל.

קלוד קורא את התיאור של כל סקיל ומחליט לבד מתי להשתמש בו - לא צריך לזכור פקודות.

התיקייה הזו ריקה בכוונה - את הסקילים בונים ביחד בשיעורים:

| סקיל | נבנה בחלק |
|------|------------|
| 🎨 `ad-image` - יצירת תמונת מודעה | 4 |
| 📅 `schedule-post` - תזמון תוכן אורגני ב-Metricool | ✅ נבנה |

> ההבדל מ-`tools/`: שם יושבים הכלים ה**נעולים** לבטיחות (העלאה ל-Meta). אותם לא בונים ולא משנים - הם מגיעים מוכנים, וזה בכוונה.
