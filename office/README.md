# 🏢 המשרד החי - הוראות הפעלה

דף בדפדפן שמראה בזמן אמת את צוות הסוכנים עובד: מי קיבל משימה, מה הוא עושה עכשיו, ואיך העבודה עוברת מסוכן לסוכן.
הכל אמיתי: מה שרואים על המסך הוא מה שקלוד קוד עושה באותו רגע.

## איך מריצים

1. פותחים טרמינל בתיקיית הפרויקט ומריצים:
   ```
   npm run office
   ```
   הדפדפן נפתח לבד על `http://127.0.0.1:4777`. אם לא - פותחים את הכתובת ידנית.
   את הטרמינל **משאירים פתוח** - הוא המשרד. סוגרים עם `Ctrl+C`.
2. **פותחים שיחה חדשה בקלוד קוד** בפרויקט הזה.
   ⚠️ חשוב: ההוקים (ה"פעמונים" שמדווחים למשרד) נטענים בפתיחת שיחה. שיחה שהייתה פתוחה לפני ההתקנה אולי לא תופיע.
3. כותבים בקשה רגילה בצ'אט. הרובוטים מתחילים לזוז.

בפינה של הדף יש נורית: **ירוקה "מחובר · חי"** = הכל תקין. **כתומה "מתחבר מחדש…"** = השרת בטרמינל לא רץ.

## מה רואים על המסך
- **ראש הצוות** (רובוט סגול עם כתר, בחזית) = השיחה הראשית. ממנו יוצאות כל המשימות.
- **רובוט לכל סוכן** מ-`.claude/agents/`. הממומן משמאל, האורגני מימין, המנכ"ל באמצע.
  סוכן שאינו ברשימה מופיע כ**עוזר כללי** (רובוט אפור עם כובע).
- **תיקייה צהובה עפה** = משימה עוברת לסוכן. **דף ירוק עף חזרה** = הסוכן סיים והחזיר תוצאה.
- **כרטיס מעל הרובוט** = מה הוא עושה ברגע זה ("קוראת קובץ: brief.md"), ועל איזו משימה.
- **זוהר צבעוני ברצפה** = הרובוט עובד. עיניים חצי סגורות ו-z-z = נח.
- **לוח המשימות על הקיר**: חדש ← בעבודה ← הושלם.
- **יומן העבודה** בצד = כל מה שקרה, צעד אחר צעד.

## תסריט דמה (בלי סוכנים אמיתיים, בלי אינטרנט)
בטרמינל **נוסף** (כשהמשרד פתוח):
```
node office/demo.js            הסיפור המלא (~70 שניות)
node office/demo.js --fast     אותו סיפור, פי 3 מהר
node office/demo.js --loop     חוזר שוב ושוב (Ctrl+C לעצירה)
```
זה גיבוי מצוין להצגה: אם אין אינטרנט או שמשהו נתקע - מריצים את הדמה, והמשרד זז בדיוק אותו דבר.

## ✅ צ'קליסט להצגה מול קהל

**יום לפני - חזרה גנרלית (חובה):**
- [ ] `npm run office`, שיחה חדשה, ובקשה **זהה** לזו שתציגו. לוודא שהרובוטים זזים ושהתוצאה טובה.
- [ ] לבחור בקשה ש**לא עולה לאוויר**: משהו שנשאר בקבצים (טיוטת קופי, בחירת תמונות, ניתוח).
      לא בקשה שמתזמנת פוסט במטריקול או מעלה ל-Meta - על הבמה אין זמן לבדוק מה יצא.
- [ ] להריץ גם `node office/demo.js --fast` ולוודא שהגיבוי עובד.
- [ ] לבדוק על המסך/מקרן האמיתי (או ברזולוציה 1920×1080) שהטקסט קריא מהשורה האחרונה.

**ביום ההצגה, חצי שעה לפני:**
- [ ] להפעיל `npm run office` ולהשאיר את הטרמינל פתוח.
- [ ] בדפדפן: מסך מלא (`F11`), זום 100% (`Ctrl+0`).
- [ ] נורית ירוקה "מחובר · חי".
- [ ] **לפתוח שיחה חדשה** בקלוד קוד - זו השיחה של ההצגה.
- [ ] להשתיק התראות במחשב (Windows: "נא לא להפריע").
- [ ] טרמינל שני מוכן עם `node office/demo.js` - למקרה חירום.
- [ ] להעתיק את הבקשה מראש, כדי להדביק ולא להקליד בלחץ.

**בזמן ההצגה:**
- המשרד עוקב אחרי **השיחה ששלחה את הבקשה האחרונה**. אם פתוחה עוד שיחה על הפרויקט - היא לא תפריע, כל עוד לא שולחים בה בקשה.
- רענון הדף (`F5`) באמצע עבודה בטוח: המשרד משחזר את המצב של הבקשה הנוכחית.

## 🛠️ אם משהו לא עובד

השאלה הראשונה תמיד: **האם הבעיה בצנרת או בתצוגה?**

**בדיקה:** מריצים בטרמינל נפרד את הפקודה הזו, שמציגה כל שורה חדשה ביומן ברגע שהיא נכתבת, וכותבים בקשה בצ'אט:
```
Get-Content office\.runtime\events.jsonl -Wait -Tail 5
```
(ב-Git Bash: `tail -f office/.runtime/events.jsonl`)

| מה רואים | מה זה אומר | מה עושים |
|----------|------------|-----------|
| **לא נוספות שורות** לקובץ | הצנרת: ההוקים לא רצים | 1. פותחים **שיחה חדשה** (הכי נפוץ). 2. בודקים שב-`.claude/settings.json` יש את ארבעת ההוקים שמפעילים `office/hooks/log-event.js`. 3. `node --version` - צריך 20 ומעלה. |
| **נוספות שורות**, אבל הדף לא זז | התצוגה | 1. נורית כתומה? הטרמינל של `npm run office` נסגר - מפעילים שוב. 2. מרעננים את הדף (`F5`). 3. השרת קורא רק שורות **חדשות** - אירועים מלפני ההפעלה לא יופיעו, וזה בכוונה. |
| "המשרד כבר פתוח בחלון אחר" | שרת אחר כבר רץ על הפורט | פשוט פותחים את הכתובת `http://127.0.0.1:4777`. או סוגרים את הטרמינל הישן. |
| הפורט תפוס ע"י תוכנה אחרת | | ב-PowerShell: `$env:OFFICE_PORT=4800; npm run office` (או כל מספר אחר) |
| עדכנתם את קלוד קוד והמשרד הפסיק לזוז | ייתכן שמבנה האירועים השתנה | מריצים כיול מחדש - ההוראות ב-`office/calibration/NOTES.md` |
| הכל נתקע 3 דקות לפני ההצגה | | `node office/demo.js --loop` ולהמשיך בביטחון 🙂 |

## גבולות (בכוונה)
- **צופה בלבד.** המשרד קורא אירועים ולא נוגע בכלים, בקבצי לקוחות או בשום דבר שעולה לאוויר.
- **מקומי בלבד.** מאזין רק ל-`127.0.0.1` - אף מחשב אחר ברשת לא רואה אותו, ולא יקפוץ חלון של חומת האש.
- **קובצי הריצה** (`office/.runtime/`) לא נכנסים לגיט. היומן מתחלף לבד כשהוא עובר 2MB.
- **ההוקים לא מאטים את העבודה:** הם רצים ברקע, ותמיד מסתיימים בהצלחה ובשקט, גם אם משהו בהם נכשל.

## מה יש בתיקייה
```
office/
  server.js            השרת המקומי (npm run office)
  public/office.html   הדף - קובץ אחד, בלי ספריות ובלי אינטרנט
  hooks/log-event.js   ההוק שקלוד קוד מפעיל
  lib/translate.js     תרגום אירוע גולמי -> משפט אנושי
  lib/roster.js        רשימת הסוכנים, צבעים ואייקונים (מ-.claude/agents)
  demo.js              תסריט הדמה
  test/                בדיקות (node --test "office/test/*.test.js")
  calibration/         הכיול: מה ההוקים באמת שולחים + בדיקת האמת
```
